# CCNA Mega Lab

> **Work in Progress**⚠️

A comprehensive CCNA practice lab based on the **CCNA Mega Lab** scenario from Jeremy's IT Lab.
The lab brings together a wide range of CCNA topics in a single multi-site enterprise network, providing an opportunity to practice configuration, troubleshooting, and verification in Cisco Packet Tracer.

The original scenario and `.pka` file are from Jeremy's IT Lab.

## Overview
The main goal of this lab is to practice multiple CCNA topics together in one integrated topology rather than as isolated exercises.
The scenario currently includes the following areas:

* Initial Device Setup
* VLANs and Layer-2 EtherChannel
* IP Addressing and Layer-3 EtherChannel
* HSRP
* Rapid Spanning Tree Protocol (RSTP)
* Static and Dynamic Routing
* DHCP, DNS, NTP, SNMP, Syslog, FTP, SSH, and NAT
* ACLs and Layer-2 Security
* IPv6
* Wireless
